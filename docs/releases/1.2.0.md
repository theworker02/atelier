# v1.2.0 — Local workflow depth

## Release summary

Version 1.2.0 deepens both Windows MVPs without widening their trust boundary. This is a local-workflow release: it adds persistence, visible expiry state, and clearer user controls while preserving the no-network, no-telemetry baseline.

## Atelier

- Adds a local workspace note that persists across restarts.
- Adds a clear-local-audit action.
- Keeps workspace references, notes, and audit data on the local device.

## Relaydesk

- Adds a 60-second local pairing-code expiry indicator.
- Adds a visible summary of granted view and input capabilities.
- Keeps the local consent timeline across restarts.

## Important limitations

Neither app adds network connectivity, remote access, hidden capture, telemetry, or external data sharing in this release.

## Upgrade notes

- Existing Atelier workspace references and audit logs remain in `%LOCALAPPDATA%\\Magnexis\\Atelier`.
- Existing Relaydesk timelines remain in `%LOCALAPPDATA%\\Magnexis\\Relaydesk`.
- There is no migration step and no account.

## Verification

Both Windows projects were built in Release configuration with the .NET 10 SDK. This release requires the .NET 10 Desktop Runtime when using the packaged ZIP.
