# v0.1.0 — Local foundations

## Atelier

- Native Windows desktop MVP.
- Choose and restore a local workspace reference.
- Record explicit review approvals in a local audit file.
- No automatic file reads, edits, provider calls, or telemetry.

## Relaydesk

- Native Windows desktop consent demonstrator.
- Local pairing-code generation and separate view/input consent states.
- Persisted local timeline.
- No device connection, screen capture, remote input, clipboard, or file transfer.

## Requirements

Windows and the .NET 10 Desktop Runtime. The source build uses the .NET 10 SDK.
