# Media capture checklist

All media must be captured from the tagged release build on Windows. Do not use mockups, generated artwork, altered screenshots, private workspace paths, or personal data.

1. A full-window screenshot after opening Atelier.
2. A screenshot with a non-sensitive test workspace selected.
3. A GIF showing a local note save and restart restoration.
4. A short video showing review recording and audit clearing.
5. Alt text and a caption that name the release version and behavior shown.
